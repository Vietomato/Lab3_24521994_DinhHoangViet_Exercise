# Project Rules

- Use React 19, Vite and JavaScript.
- Use functional components and ES6 default parameters.
- Build DeveloperCard and SkillBadge as separate components.
- Do not use div tags inside DeveloperCard.jsx.
- Use semantic HTML: article, header, hgroup, dl, dt, dd, ul, li.
- Use stable IDs as list keys.
- Use CSS Modules and CSS Custom Properties.
- Do not use inline styles.
- Avatar images must use HTTPS and explicit width/height.
- Show initials when the avatar cannot load.
- Support a 375px viewport without horizontal scrolling.
- Implement one task at a time.
